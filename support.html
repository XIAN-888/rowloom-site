Rowloom — Support

Use your own pattern to plan, rehearse and check each row, with a reviewed return to a saved working state when needed.

Import a pattern

Choose Import and select your PDF or image in Files. Use a file that you can open and are entitled to use. Large images may be optimized for reading; the source file you selected is not overwritten. If a document will not open, try an unlocked PDF or a smaller image.

Build a plan for your own pattern

Open an imported project and its piece, then open the execution plan from the worktable. Enter each stage's actual starting row, pattern starting row, number of pattern rows and repeats. Save a source position by browsing the pattern yourself. Stages must not overlap. Save the complete plan to apply it; leaving a draft does not change completed rows. You can continue reading and counting manually without a plan. Rowloom does not automatically interpret a pattern or move the ruler as rows advance.

Rehearse any row without advancing

In the plan editor, choose an actual row to review the current draft. The read-only rehearsal shows its stage, pattern row, repeat, all due actions and any saved source page. It does not advance the counter, record checks or replace your reading position. A row outside the stages is identified so you can check your manual rules. Correct the draft if the mapping or actions do not match your pattern, then save the complete plan when ready.

Check simultaneous actions

The execution worktable lists every action due on the current actual row. Check each one explicitly before finishing that row. One check does not complete other actions due at the same time. Records belong to the saved plan revision; after changing a plan, the current row needs checking under the new plan. Checks are your own records, not an inspection of the physical knitting. The separate execution practice starts at actual row 11, where a decrease and a color change coincide.

Name, preview and restore a checkpoint

Save a named checkpoint at a reliable point. It keeps completed rows, execution plan, repeat rules and reminders, action checks, note and reading/ruler position separately from recent undo history. Select it to review the before/after state and affected checks. Cancel leaves the project as it is. Confirming restores that saved state together; Undo can return to the state before restoration. In the practice, the checkpoint after 8 completed rows returns to actual row 9 next. App recovery does not undo physical knitting or place a physical lifeline.

Count rows and place the ruler

Open a project and select its piece. Advance the counter after finishing a row. The displayed pattern row can follow your repeat plan. Tap the pattern to place the manual ruler and reposition it as needed; the ruler does not automatically follow the counter. Row reminders appear inside the reader, not as scheduled system notifications.

Pieces, pauses and corrections

Each piece keeps its own progress, reading position, note and rules. Save a note before taking a break. Undo restores recent saved changes. Rewind moves the count back while preserving the current note and rules; adjust the ruler if an earlier reading position is no longer in recent history. A finished project can be resumed.

Free projects and Pro

Three personal projects can be kept free; practice samples do not count. Pro lets you add more personal projects from new imports. All tools in existing projects, full backup export and restoration stay available without Pro and after an annual subscription expires. If you already have three or more personal projects, adding another new import requires Pro.

Back up or move to another device

In Settings, choose Export full backup and save the file to a location you control, such as iCloud Drive in Files. Backups contain the patterns, pieces, progress and rules. To restore, select the backup, review its contents and confirm. Restoration adds copies and keeps existing projects. Repeated restoration may create more copies. This is a manual backup workflow, not automatic synchronization. Keep a current backup before deleting projects or the app. Saved project data also includes execution plans, action confirmation records and named checkpoints.

Purchases and restoration

Use the same Apple Account to restore a yearly or Lifetime purchase from the Pro screen. Apple handles payment and subscription management. Cancel an annual subscription in your Apple Account settings. Buying Lifetime access does not automatically cancel an existing subscription. For purchase problems, first check the Apple Account and current App Store status.

Pattern rights and help

Only import patterns that you own or have permission to use. A backup can contain the full pattern, so keep it private unless sharing is permitted. Contact xiangguoxin520@icloud.com with the app version, device/system version and a brief description of the issue. Do not send complete copyrighted patterns or unrelated personal information unless needed and you have permission.
