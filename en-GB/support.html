Rowloom — Support

A practical guide to importing a pattern, keeping your place and protecting your progress.

Import a pattern

Choose Import and select your PDF or image in Files. Use a file that you can open and are entitled to use. Large images may be optimized for reading; the source file you selected is not overwritten. If a document will not open, try an unlocked PDF or a smaller image.

Count rows and place the ruler

Open a project and select its piece. Advance the counter after finishing a row. The displayed pattern row can follow your repeat plan. Tap the pattern to place the manual ruler and reposition it as needed; the ruler does not automatically follow the counter. Row reminders appear inside the reader, not as scheduled system notifications.

Pieces, pauses and corrections

Each piece keeps its own progress, reading position, note and rules. Save a note before taking a break. Undo restores recent saved changes. Rewind moves the count back while preserving the current note and rules; adjust the ruler if an earlier reading position is no longer in recent history. A finished project can be resumed.

Free projects and Pro

Three personal projects can be kept free; practice samples do not count. Pro lets you add more personal projects from new imports. All tools in existing projects, full backup export and restoration stay available without Pro and after an annual subscription expires. If you already have three or more personal projects, adding another new import requires Pro.

Back up or move to another device

In Settings, choose Export full backup and save the file to a location you control, such as iCloud Drive in Files. Backups contain the patterns, pieces, progress and rules. To restore, select the backup, review its contents and confirm. Restoration adds copies and keeps existing projects. Repeated restoration may create more copies. This is a manual backup workflow, not automatic synchronization. Keep a current backup before deleting projects or the app.

Purchases and restoration

Use the same Apple Account to restore a yearly or Lifetime purchase from the Pro screen. Apple handles payment and subscription management. Cancel an annual subscription in your Apple Account settings. Buying Lifetime access does not automatically cancel an existing subscription. For purchase problems, first check the Apple Account and current App Store status.

Pattern rights and help

Only import patterns that you own or have permission to use. A backup can contain the full pattern, so keep it private unless sharing is permitted. Contact xiangguoxin520@icloud.com with the app version, device/system version and a brief description of the issue. Do not send complete copyrighted patterns or unrelated personal information unless needed and you have permission.
