Rowloom — 사용 안내

내 도안으로 계획을 세우고 원하는 단을 미리 확인한 뒤 각 동작을 체크하세요. 필요하면 변경 내용을 확인하고 저장된 작업 상태로 돌아갈 수 있어요.

내 도안 불러오기

가져오기를 선택하고 파일에서 PDF나 이미지를 고르세요. 열 수 있고 사용 권한이 있는 파일을 이용해 주세요. 큰 이미지는 기기에서 읽기용으로 최적화할 수 있지만 선택한 원본 파일을 덮어쓰지 않습니다. 열리지 않으면 잠기지 않은 PDF나 작은 이미지를 시도해 보세요.

내 도안으로 계획 만들기

불러온 프로젝트와 부품을 열고 작업대에서 실행 계획을 여세요. 각 구간의 실제 시작 단, 도안 시작 단, 도안의 단수와 반복 횟수를 입력하고 직접 도안을 보며 참조 위치를 저장하세요. 구간의 실제 단 범위는 겹칠 수 없어요. 전체 계획을 저장해야 적용되며 초안을 닫아도 완료 단수는 바뀌지 않아요. 계획 없이 직접 읽고 단수를 세는 방식도 쓸 수 있어요. 도안을 자동으로 해석하거나 단수에 따라 눈금자를 자동으로 옮기지는 않아요.

진행을 바꾸지 않고 원하는 단 미리 보기

계획 편집기에서 실제 단을 선택하면 현재 초안의 구간, 도안의 단, 반복 횟수, 해당하는 모든 동작과 저장된 참조 페이지를 볼 수 있어요. 읽기 전용 미리 보기는 단수를 올리거나 체크를 기록하거나 현재 읽기 위치를 바꾸지 않아요. 구간에 포함되지 않는 단도 표시되므로 수동 규칙을 확인할 수 있어요. 도안과 맞지 않으면 초안을 고치고 준비된 뒤 전체 계획을 저장하세요.

같은 단의 동작을 각각 확인하기

실행 작업대에는 현재 실제 단의 모든 동작이 표시돼요. 각 동작을 직접 체크해야 단을 마칠 수 있어요. 하나를 체크해도 같은 단의 다른 동작은 완료되지 않아요. 기록은 저장된 계획 버전에 연결되어 계획을 바꾸면 현재 단을 새 계획으로 다시 확인해야 해요. 체크는 내 기록이며 실제 편물을 검사한 결과가 아니에요. 별도 연습 예시는 코줄임과 색 바꾸기가 겹치는 실제 11단에서 시작해요.

체크포인트 저장, 미리 보기와 복원

확실한 지점에서 이름 있는 체크포인트를 저장하세요. 완료 단수, 실행 계획, 반복 규칙과 알림, 동작 체크, 메모, 읽기·눈금자 위치를 최근 실행 취소 기록과 별도로 보관해요. 선택하면 복원 전후와 영향을 받는 체크를 볼 수 있고 취소하면 프로젝트는 그대로예요. 확인하면 저장된 상태를 함께 복원하며 실행 취소로 복원 전에도 돌아갈 수 있어요. 연습의 8단 완료 체크포인트로 돌아가면 다음은 실제 9단이에요. 앱 복원은 편물을 풀거나 실제 라이프라인을 넣는 작업을 대신하지 않아요.

단수와 수동 눈금자

프로젝트에서 부품을 고른 뒤 한 단을 마칠 때마다 단수를 올리세요. 도안의 현재 단은 반복 규칙에 맞춰 표시할 수 있습니다. 도안을 눌러 눈금자를 놓고 직접 옮겨 주세요. 단수에 따라 자동 이동하지 않습니다. 단 알림은 도안 화면에 표시되며 예약된 시스템 알림이 아닙니다.

부품, 쉬는 시간과 수정

부품마다 진행 상황, 읽던 위치, 메모와 규칙이 따로 저장됩니다. 쉬기 전에 메모를 남겨 보세요. 실행 취소는 최근 변경을 되돌립니다. 이전 단으로 돌아가도 현재 메모와 규칙은 유지됩니다. 예전 위치가 최근 기록에 없으면 눈금자를 조정해 주세요. 완료한 프로젝트도 다시 이어갈 수 있습니다.

무료 개수와 Pro

내 프로젝트 세 개까지 무료이며 연습 예시는 세지 않습니다. Pro는 새 도안으로 프로젝트를 더 추가하기 위한 기능입니다. 기존 프로젝트의 도구와 전체 백업 내보내기·복원은 미구매 상태와 연간 구독 만료 후에도 사용할 수 있습니다. 내 프로젝트가 이미 세 개 이상이라면 새로 불러오려면 Pro가 필요합니다.

백업과 기기 이동

설정에서 전체 백업 내보내기를 선택하고 파일의 iCloud Drive 등 관리할 수 있는 곳에 저장하세요. 도안, 부품, 진행 상황과 규칙이 들어 있습니다. 복원할 때는 내용을 확인하고 진행하세요. 기존 프로젝트를 유지하며 사본을 추가하므로 반복 복원하면 사본이 늘어날 수 있습니다. 수동 백업이며 자동 동기화가 아닙니다. 프로젝트나 앱을 삭제하기 전에 최신 백업을 보관하세요. 저장된 프로젝트 데이터에는 실행 계획, 동작 확인 기록과 이름 있는 체크포인트도 포함됩니다.

구매와 구매 복원

같은 Apple 계정으로 Pro 화면에서 연간 구독이나 평생 구매를 복원하세요. 결제와 구독 관리는 Apple이 처리합니다. 연간 구독은 Apple 계정 설정에서 취소할 수 있습니다. 평생 구매를 해도 기존 구독은 자동 취소되지 않습니다. 문제가 있으면 계정과 App Store 상태를 먼저 확인하세요.
